# NYC Squirrel Census SQL Project
Analyzed squirrel population and behavior data using SQL and SQLite.

## Tools
- SQLite
- VS Code

## Questions Explored
- Fur color distribution
- AM vs PM shifts
- Common squirrel behaviors

## Key Findings
- Gray squirrels were the most common by far
- More squirrel sightings occurred during PM shifts
- Foraging was more common than chasing
